### 手机类常见问题
- **IP68 可以带着洗澡/游泳吗？** IP68 仅保证实验室清水条件短时浸泡，**不防热水、海水、水蒸气，且人为进水不在保修范围**，不建议洗澡或游泳使用。
- **不同版本怎么选？** 运存影响多任务与流畅年限，存储影响照片/应用容量；长期使用建议至少 12+256GB。
- **充电头是否随附？** 本系列均随附对应功率充电头；若使用第三方头需支持同协议才能满速。
- **双卡/内存扩展？** 支持双 Nano-SIM（部分版本一卡一存），不支持存储卡扩展，建议按容量一步到位。

- **鼠标漂移/丢帧？** 检查电量、接收器距离与鼠标垫，关闭多余 DPI 软件；玻璃/反光桌面需配鼠标垫。

### 移动存储类常见问题
- **速度达不到标称？** 需主板/线材支持 USB 3.2 Gen2，接 USB2.0 或劣质线会大幅降速；大文件持续写入发热后也会降速。
- **能给手机扩容吗？** 双接口/支持 OTG 的 C 口盘可直连安卓手机/平板，iPhone 需对应接口或转接头。
- **数据安全？** 重要数据建议多盘/云端备份，闪存损坏数据恢复困难；可启用硬件/软件加密。

### 扩展坞类常见问题
- **接上不供电/不显示？** 先把 PD 充电头接扩展坞供电口；部分轻薄本需原装或高功率充电器。

- **网口/读卡无反应？** 首次使用部分系统需自动安装驱动；检查设备是否已被识别。
