### 充电宝类常见问题（真实规则）
- **充电宝能带上飞机吗？** 充电宝不可托运。额定能量限制只是乘机条件之一。中国境内航班还要求清晰的3C标识，无3C标识、标识不清晰及被召回型号或批次禁止携带。演示商品没有真实认证和召回状态，不得根据99.9Wh等参数保证可以登机。出行前核实实物标识、召回信息及航司和机场最新要求。 来源：https://www.caac.gov.cn/XWZX/MHYW/202506/t20250626_227805.html；核对日期：2026-10-09。
- **电池容量和额定容量有什么区别？** 电池容量是电芯总容量；额定容量是经转换损耗后实际能输出给手机的容量，数字更小属正常。
- **为什么充不了笔记本？** 需要充电宝 C 口支持 PD 高功率（如 65W）并使用对应 C-C 线，普通 5V 充电宝无法驱动笔记本。

### 充电器类常见问题
- **氮化镓（GaN）好在哪？** 同功率下体积更小、发热更低、转换效率更高。
- **多口同时充功率怎么分？** 多设备接入后按设备需求智能分配，单口最大功率会相应降低，属正常现象。
- **出国能用吗？** 100–240V 宽电压充电器可配合转换插头在多数国家使用，但插脚标准不同需转换头。

### 线材/无线充类常见问题
- **为什么线只能慢充？** 高功率需带 E-Marker 的 C-C 线；普通 A-C 或无线材受接口与协议限制。
- **无线充比有线慢？** 无线充电有转换损耗且易发热，通常功率低于有线，属正常；厚手机壳或金属贴片会影响充电。
- **MFi 是什么？** 苹果配件的官方认证，未认证的 L 线可能弹窗或不兼容。
